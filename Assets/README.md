Escape Room

---

Nu har vi övat på förflyttning, rotation, och raycasting i Unity. Med hjälp av dessa funktioner har ni nu som uppgift att bygga upp en enkel spelprototyp i formen av ett Escape Room.
Spelaren skall börja i ett rum. I rummet finns en knapp och en dörr. Försök att göra så att man kan trycka på knappen för att öppna dörren.

- Ni får använda valfri typ av förflytting (Translate, Physics, etc.).
- Utöver detta får ni själva skapa mer funktionalitet eller pussel.
- Kom ihåg att pusha till Github med bra commit-meddelanden.

Som inlamning skall ni skicka en lank till ert Github repository. Se till att det är
publikt eller att jag är inbjuden (KehlerCreations).
